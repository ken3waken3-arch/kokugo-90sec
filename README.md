# 国語科｜続けること・変えること。その理由は？

文部科学省の審議まとめを、国語科の「続けて大切にする方向」「見直す方向」「なぜ見直すのか」に分けた教育情報サイトです。資料の事実と授業への提案も分けて示します。

## 内容物

- `index.html`：スマートフォン対応、キーワード検索、出典案内を備えたページ
- `assets/video-slide-01.png`〜`06.png`：解説用スライド画像
- `assets/国語-変更点解説ナレーション.m4a`：CanvaのAI音声「あいり」（約95秒、音声のみ）
- `国語_変更点解説_6スライド.pptx`：Canvaに取り込んだ編集用6枚スライド
- `配布資料.pdf`：A4一枚
- `90秒解説台本.txt`、`字幕.srt`、`字幕.vtt`：ナレーション原稿と字幕
- `Canva動画化手順.md`：編集デザインと書き出し時の注意
- `公開手順.md`：国語専用GitHub Pagesサイトへの公開手順

## 再生形式について

Web版は音声なしで約90秒再生するスライド形式です。Canvaで作成したナレーションはこのサイトに含まれていません。CanvaのMP4書き出しを確認したところ、映像トラックのない音声ファイルとして出力されました。そのためMP4を制作済みとは表示せず、未完成のMP4も掲載していません。編集デザインには6枚のスライドとAIナレーションがあります。

## 資料を読むときの注意

根拠は文部科学省「次期学習指導要領等に向けた審議まとめ」（2026年10月5日）資料1/4、国語の印刷頁127–140（PDF頁128–141）です。これは確定した学習指導要領ではありません。「話や文章の機能」の4分類は資料中の仮称・例示です。授業例は資料の方向性をもとにした提案です。
